# Chess ♔

A two-player chess game running in the browser. No accounts, no AI — just you and a friend.

**Play:** [https://eduardoccbot.github.io/chess](https://eduardoccbot.github.io/chess)

## Features

- Full two-player chess (all rules including castling, en passant, pawn promotion)
- Algebraic notation move list
- Captured pieces display
- Check/checkmate/stalemate detection
- Highlighted legal moves and en passant squares
- Responsive — works on mobile and desktop
- No dependencies — pure HTML/CSS/JS

## Running locally

```bash
python3 server.py
# Open http://localhost:8080
```

Or open `index.html` directly in any browser.

## Tech

Single HTML file — no build step, no frameworks. Standard SVG chess pieces.
